# beer-review-predictability
Consumer Sensory Rating Structure and Cross-Attribute Predictability: Evidence from Online Beer Reviews
This repository contains available analytical data, scripts, model outputs and documentation supporting a study of cross-attribute taste-score predictability in online beer reviews. The materials include corrected sample-size sensitivity analysis outputs and documentation of the original and grouped-validation experiments. File-level availability and reproduction limitations are specified in the README.
Citation - Siyanbola, H. O. (2026). Consumer Sensory Rating Structure and Cross-Attribute Predictability: Evidence from Online Beer Reviews — Research Data and Code [Data set]. Zenodo. https://doi.org/10.5281/zenodo.22918775
